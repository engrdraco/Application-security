# Application Security Portfolio

Welcome to my Application Security (AppSec) and penetration testing repository. This space serves as a technical portfolio documenting my hands-on research, vulnerability exploitation, and remediation labs. 

Through continuous challenge platforms like **TryHackMe** and **HackTheBox**, paired with specialized research into **API Security**, I have developed a deep understanding of the adversarial mindset. By understanding exactly how applications are broken, I have equipped myself with the tactical engineering skills required to identify, triage, and mitigate critical security flaws before they ever reach production.

---

##  The AppSec Mindset & Core Capabilities

True application security requires looking past generic scanner alerts and understanding the underlying logic of a codebase. My hands-on experience spans the entire web stack, moving from initial reconnaissance to deep exploitation and final remediation advice. 

Using **Kali Linux** as my primary testing environment, I specialize in analyzing application traffic, identifying hidden endpoints, and uncovering structural flaws in software architecture. My approach treats hacking not just as a way to find bugs, but as a methodology for building more resilient, secure-by-design systems.

---

##  Specialized Technical Skillset

### 1. API Security & Endpoint Assessment
* **Focus:** Auditing RESTful and GraphQL APIs for logic flaws, authorization bypasses, and data exposure.
* **Core Skills:** Mapping hidden endpoints, manipulating parameters to trigger Broken Object Level Authorization (BOLA/IDOR), and testing authentication mechanics (JWT exploitation, rate-limiting bypasses).
* **Tools:** Burp Suite, Postman, GoBuster/Dirsearch.

### 2. Web Application Penetration Testing
* **Focus:** Identifying and exploiting flaws across the OWASP Top 10 vulnerabilities.
* **Core Skills:** Triaging Cross-Site Scripting (XSS), SQL Injection (SQLi), Server-Side Request Forgery (SSRF), and broken access controls.
* **Methodology:** Manual verification and exploitation to eliminate false positives and understand true business impact.

### 3. Linux Environments & Tooling (Kali Linux)
* **Focus:** Operating a streamlined, command-line-driven environment for rapid security auditing and automation.
* **Core Skills:** Bash scripting for automated recon, advanced network analysis, and utilizing standard industry frameworks (`nmap`, `wfuzz`, `hydra`, `sqlmap`).
